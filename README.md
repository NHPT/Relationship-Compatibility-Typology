# RCT 关系适配类型学

Relationship Compatibility Typology

不测性格，只测**关系**。通过 20 个日常场景的行为选择，识别一个人（或任意两人）在相处中的真实模式，判断两个人是否适合一起走远。

**适用场景**：婚恋伴侣 · 搭伙创业 · 长期伙伴 · 团队协作

## 类型体系（8 型 + 2 警示）

三主轴交叉出 8 个基础型，加 2 个警示型。

**三主轴**：

| 主轴 | 两极 |
|---|---|
| X 人生主轴 | 安稳守成 ↔ 进取攀登 |
| Y 关系形态 | 深度共生 ↔ 独立并置 |
| M 金钱模式 | 规划积累 ↔ 即时体验 |

**8 型完整定义**：

| 家族 | 规划积累 | 即时体验 |
|---|---|---|
| A 安稳共栖 | A1 安稳共栖·稳重型 | A2 安稳共栖·温情型 |
| B 安稳自在 | B1 安稳自在·克制型 | B2 安稳自在·随性型 |
| C 并肩进取 | C1 并肩进取·务实型 | C2 并肩进取·激情型 |
| D 自由追梦 | D1 自由追梦·理性型 | D2 自由追梦·洒脱型 |

- **E 回避压抑型**（警示）：冲突回避主导，冷战死锁。
- **F 边界模糊型**（警示）：忠诚/家庭边界模糊，信任危机。
- **SWING 摇摆型**：主轴未定型，需拉长观察。

## 核心设计

- **动态出题**：题库是 32 个「考点模板 + 参数池」，每次测试随机抽考点、随机替换参数，题面几乎不重复，防背答案。
- **全场景行为题**：不测价值观表态，只测行为选择；每个选项都体面，无显性坏答案。
- **交叉验证**：每个维度多题多场景综合评估，单题不决定结果。
- **限时作答**：每题 15 秒，逼人凭直觉，降低伪装空间。
- **多次测试**：结果存浏览器本地，多次测试后自动聚合出「稳定类型 + 一致率 + 稳定性」，低稳定即提示"可能伪装或处于转折期"。

## 技术栈

纯静态前端，**无后端、无构建**：HTML + CSS + 原生 JavaScript。数据存 `localStorage`。

## 本地运行

```bash
cd Relationship-Compatibility-Typology
python3 -m http.server 8090
# 打开 http://localhost:8090
```

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库。
2. 推送本项目：

```bash
git init

git commit -m "init"
git branch -M main
git remote add origin https://github.com/<用户名>/Relationship-Compatibility-Typology.git
git push -u origin main
```

3. 仓库 **Settings → Pages → Branch 选 `main`（根目录）→ Save**。

## 使用边界

- 类型是地图，不是判决；描述"相处模式"，不评判"人品好坏"。
- 看行为一致性，不看漂亮答案；自测结果要和真实行为交叉验证。
- 警示型（E/F）不等于没救，而是"先处理冲突/边界，再谈匹配"。
- 低稳定性本身就是结论：多次结果跳变，说明行为不一致、在伪装，或处于人生转折期。
